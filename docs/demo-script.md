# سناریوی دموی پنج‌دقیقه‌ای

دمو را در آزمایشگاه محلی ضبط کنید. از ابتدا اعلام کنید که Codex و اجرای
برنامه‌ها واقعی‌اند و API ابری شبیه‌سازی می‌شود. حساب و توکن لیارا لازم نیست.
کلیدها، فایل .env و تنظیمات شخصی را در ویدئو نمایش ندهید.

1. ۰:۰۰ تا ۰:۳۰: مسئلهٔ صاحب سایت و مسیر درخواست، طرح، تأیید، اجرا و بررسی نتیجه.
2. ۰:۳۰ تا ۲:۰۰: پروژهٔ نمونهٔ Node، پلن آزمایشی و پورت محلی، فهرست فایل‌ها و hash.
   تأیید طرح، ساخت برنامه، آپلود سورس، release و بازکردن سایت و /health واقعی.
3. ۲:۰۰ تا ۳:۳۰: خطایی قابل‌بازتولید در برنامهٔ آزمایشی، درخواست فارسی برای
   عیب‌یابی، بازکردن شواهد و محدودیت داده، پیشنهاد اصلاح و مقایسهٔ نتیجه.
4. ۳:۳۰ تا ۴:۲۰: اتصال MCP از Codex یا Claude Code، پیشنهاد طرح و تأیید در همان
   رابط. رد یک طرح یا ادامهٔ کار پس از restart را نمایش دهید.
5. ۴:۲۰ تا ۵:۰۰: مدیریت env و دامنه در صورت آماده‌بودن. محدودیت ثبت‌کننده،
   DNS و صدور TLS، نتیجهٔ تست‌ها، لینک GitHub و مستندات را توضیح دهید.

قبل از ضبط، سناریو را یک بار در همان آزمایشگاه محلی اجرا کنید.
ویدئوی نهایی هنوز ضبط نشده است.
